# Yash Gound - Personal Portfolio 🚀

A sleek, modern, and highly aesthetic personal portfolio website designed to showcase my projects, skills, and experience as a Software Developer. Built from scratch focusing on performance, smooth micro-animations, and a premium dark-mode aesthetic.

## 🔗 Live Preview
[View Live Portfolio](https://YashG1195.github.io/portfolio-yash/) *(Note: Link will be active once GitHub Pages is enabled)*

## ✨ Features
- **Premium Dark Mode Design**: High-contrast, sleek aesthetic with vibrant gradient accents.
- **Glassmorphism UI**: Beautiful, frosted-glass effects on the navigation bar and interactive overlays.
- **Smooth Animations**: Custom scroll-triggered fade-ins and dynamic hover states for a fluid experience.
- **Custom Cursor**: Interactive cursor tracking that expands when hovering over clickable elements.
- **Fully Responsive**: Optimized for perfect viewing across desktop, tablet, and mobile devices.

## 🛠️ Tech Stack
This project was intentionally built using a pure, vanilla tech stack to ensure lightning-fast performance and full control over the design system:
- **HTML5** (Semantic structuring)
- **CSS3** (Vanilla CSS with Custom Properties, Flexbox, Grid)
- **JavaScript (ES6+)** (Intersection Observer API for scroll animations, DOM manipulation)

## 📁 Sections Included
1. **Hero**: Dynamic introduction and core objective statement.
2. **Featured Projects**: High-quality showcase of recent academic and personal work (Eco-Valuate, TrustPulse, Stock Sense).
3. **About**: Education background, structured technical skills, and certifications.
